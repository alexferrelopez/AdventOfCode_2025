# Advent of Code 2025

This repository contains my solutions to Advent of Code, a yearly December coding challenge created by Eric Wastl.
The event runs for 12 days, with puzzles that increase in complexity each day and can be solved in any programming language.

<img width="684" height="589" alt="image" src="https://github.com/user-attachments/assets/1084c661-366c-4b43-b6c0-fe28120aed4f" />

Each day has 2 parts, the 2nd usually being a bit harder than the 1st.

Inputs are not included in this repository, following the official guidelines.
